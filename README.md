# 월-E와 사라진 미술사

`dist/index.html`을 브라우저에서 열어 플레이합니다. 작품 이미지와 게임 로직은 로컬에 포함되어 있으며 서버 설치가 필요하지 않습니다. 작품 이미지와 `index.html`, `style.css`, `game.js`를 함께 보관하세요. 교사용 정답과 운영 안내는 `교사용_진행안.md`에 있습니다.

진행 상태와 타이머는 각 기기의 브라우저에 저장됩니다. 팀 간 자동 동기화 기능은 없으며 최종 문제는 대화로 협력합니다. 화면의 ‘처음부터’를 눌러 해당 기기의 진행을 초기화할 수 있습니다. 정답은 브라우저 코드에 포함되어 있어 평가 보안 용도에는 적합하지 않습니다.
